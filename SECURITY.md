# Source and parser safety

Original JB is immutable. Outputs resolve under output/ and reject source overlap; linked build trees and staged path traversal are blocked. Parsers validate bounds/counts and H7A decoded limits. Converters use argument lists without shell execution and capture status/output with timeout. Mod folder staging validates identity and source preconditions before copy; generated JB publication is transactional, patch bytes exact and unpatched bytes compared.

Never commit game/private-save/extracted assets or secrets. Do not force-add ignored fixtures. Runtime/codec/geometry uncertainty must not become enabled destructive controls. Converter provenance and binary distribution notices remain unresolved release gates in docs/rebuild/CONVERTER_PROVENANCE.md. Send security findings privately through the repository owner's available channel; no issue containing private game bytes or credentials.
