# Performance evidence

The rebuild adds bounded streaming, precomputed IFF spans, constant-time companion lookup, throttled Qt progress and chunked build verification. Reproducible tools are in tools/rebuild/verify_game.py. Environment-specific measurements and inventories are excluded from public documentation. No numerical performance claim is made by this public summary.

Persistent cache acceleration, peak-memory profiling and the remaining acceptance measurements are still work. Structural validation does not establish console gameplay.
